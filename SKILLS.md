# Included Skills

This repository is one sharing and versioning unit for three separately triggerable Skills:

| Skill | Role |
| --- | --- |
| `bootstrap-agent-repo` | Initialize Agent-facing guidance, project branch policy and reviewed external-source registration without modifying business code. |
| `save-checkpoint` | Freeze staged changes and configured external-source fingerprints, then dispatch the checkpoint child. |
| `checkpoint-maintenance` | Review frozen Git/external evidence, maintain docs, accept reviewed baselines, commit, verify and hand back. |

Install the three paths together when you want the complete workflow. They remain sibling Skills after installation.
