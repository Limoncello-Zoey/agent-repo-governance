# Included Skills

This repository is one sharing and versioning unit for three separately triggerable Skills:

| Skill | Role |
| --- | --- |
| `bootstrap-agent-repo` | Initialize or retrofit Agent-facing repository guidance without modifying business code. |
| `save-checkpoint` | Freeze an explicit staged snapshot and dispatch the checkpoint child. |
| `checkpoint-maintenance` | Maintain affected docs and indexes, commit the frozen tree, verify it, and hand back. |

Install the three paths together when you want the complete workflow. They remain sibling Skills after installation.
